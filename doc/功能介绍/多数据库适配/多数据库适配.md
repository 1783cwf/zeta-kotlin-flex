# 多数据库适配

本文档总结了项目中实体类多数据库适配的规范和最佳实践。

## 支持的数据库

- PostgreSQL（默认）
- MySQL
- Oracle
- 达梦（DM）

## 适配原则

1. **使用 @field:AutoColumns 注解**
   - 将原来的 @AutoColumn 改为 @field:AutoColumns
   - 每个字段可以配置多个数据库的类型

2. **默认数据库配置**
   - PostgreSQL 作为默认数据库（不指定 dialect）
   - 其他数据库需要明确指定 dialect

3. **常量使用规则**
   - 通用常量直接使用（如 VARCHAR、INT、BIGINT 等）
   - 只有特定数据库才有的类型才使用对应数据库的常量类

4. **注解职责分离原则**
   - **@field:Column 注解**：负责字段映射和注释说明
     - 必须设置 `value` 属性指定数据库字段名
     - 必须设置 `comment` 属性提供字段注释
   - **@AutoColumn 注解**：只负责数据库类型定义和约束
     - 禁止设置 `value` 属性（字段名已在 @field:Column 中定义）
     - 禁止设置 `comment` 属性（注释已在 @field:Column 中定义）

## 数据库类型映射规则

### 1. 字符串类型

**常规字符串（VARCHAR）**
```kotlin
@field:Column(value = "name", comment = "名称")
@field:AutoColumns(
    AutoColumn(type = VARCHAR2, length = 32, dialect = DatabaseDialect.Oracle),
    AutoColumn(type = VARCHAR, length = 32)
)
```
- PostgreSQL/MySQL/DM: VARCHAR
- Oracle: VARCHAR2

**大文本类型**
```kotlin
@field:Column(value = "params", comment = "请求参数")
@field:AutoColumns(
    AutoColumn(type = CLOB, dialect = DatabaseDialect.Oracle),
    AutoColumn(type = LONGTEXT, dialect = DatabaseDialect.MySQL),
    AutoColumn(type = TEXT)
)
```
- PostgreSQL/DM: TEXT
- MySQL: LONGTEXT
- Oracle: CLOB

### 2. 数值类型

**整数类型（TINYINT/INT/BIGINT）**
```kotlin
@field:Column(value = "sort_value", comment = "排序")
@field:AutoColumns(
    AutoColumn(type = NUMBER, dialect = DatabaseDialect.Oracle),
    AutoColumn(type = INT)
)
```
- PostgreSQL/MySQL/DM: TINYINT/INT/BIGINT
- Oracle: NUMBER

### 3. 日期类型
根据数据库情况使用date datetime timestamp
```kotlin
@field:Column(value = "birthday", comment = "生日")
@field:AutoColumns(
    AutoColumn(type = DATE, dialect = DatabaseDialect.Oracle),
    AutoColumn(type = DATE)
)
```


### 4. 布尔类型

```kotlin
@field:Column(value = "hide", comment = "是否隐藏")
@field:AutoColumns(
    AutoColumn(type = CHAR, length = 1, defaultValue = "N", dialect = DatabaseDialect.Oracle),
    AutoColumn(type = BOOLEAN, defaultValue = "false")
)
```
- PostgreSQL: BOOLEAN
- MySQL: BOOLEAN（底层是TINYINT(1)的别名）
- Oracle: CHAR(1)，使用 'Y'/'N' 约束
- DM: BOOLEAN

## 常量导入规范

### 1. 统一的导入风格
```kotlin

// Oracle特定类型
import org.dromara.autotable.annotation.oracle.OracleTypeConstant.VARCHAR2
import org.dromara.autotable.annotation.oracle.OracleTypeConstant.NUMBER
import org.dromara.autotable.annotation.oracle.OracleTypeConstant.CLOB
import org.dromara.autotable.annotation.oracle.OracleTypeConstant.CHAR

// MySQL特定类型
import org.dromara.autotable.annotation.mysql.MysqlTypeConstant.LONGTEXT
```

### 2. 通用常量类型
通用常量优先使用com.zetaframework.mybatisflex.constant.DBTypeConstant中的
直接使用以下常量（无需前缀）：
- **字符串**: VARCHAR, TEXT, CHAR
- **整数**: INT, BIGINT, TINYINT
- **日期**: DATE, DATETIME, TIMESTAMP
- **布尔**: BOOLEAN, BOOL

这些常量在PostgreSQL、MySQL和DM数据库中通用。

## 最佳实践

### 1. 简化配置
- 如果只有Oracle的类型不同，其他数据库都相同，只配置Oracle和默认即可
- 如果MySQL和DM类型相同，可以合并配置

### 2. 导入风格统一
- 使用通配符导入通用常量
- 明确导入特定数据库的常量
- 保持代码风格一致
- 禁止使用通配符导入！！！禁止使用通配符导入！！！禁止使用通配符导入！！！

### 3. 解决常量冲突
- 不同数据库的同名常量（如Oracle的DATE）需要明确指定
- Oracle特定类型必须使用全限定名

### 4. 注解格式规范
```kotlin
// 正确格式
@field:Column(value = "字段名", comment = "字段说明")
@field:AutoColumns(
    // Oracle 配置（如果有差异）
    AutoColumn(type = Oracle类型, ..., dialect = DatabaseDialect.Oracle),
    // MySQL 特殊配置（如果需要）
    AutoColumn(type = MySQL类型, ..., dialect = DatabaseDialect.MySQL),
    // 默认配置（适用于PostgreSQL、DM等）
    AutoColumn(type = 通用类型, ...)
)

// 错误格式（避免使用）
@field:AutoColumns(
    AutoColumn(value = "字段名", type = 类型, comment = "注释")  // 不应在AutoColumn中设置value和comment
)
```

## 注意事项

1. **DM数据库**：大部分类型与MySQL相同，不存在LONGTEXT类型，使用TEXT即可
2. **Oracle**：
   - 字符串使用VARCHAR2而不是VARCHAR
   - 布尔值使用CHAR(1)配合Y/N约束
   - 大文本使用CLOB
   - 数值类型使用NUMBER
3. **默认值**：布尔值在不同数据库中使用不同的默认值（Oracle: "N", 其他: "false"）
4. **类型常量**：Oracle的DATE类型需要明确使用OracleTypeConstant.DATE以避免冲突

## 示例实体类

```kotlin
import com.mybatisflex.annotation.Column
import org.dromara.autotable.annotation.oracle.OracleTypeConstant.VARCHAR2
import org.dromara.autotable.annotation.oracle.OracleTypeConstant.CHAR

@AutoTable(value = "example", comment = "示例表")
class Example {
    @field:Column(value = "name", comment = "名称")
    @field:AutoColumns(
        AutoColumn(type = VARCHAR2, length = 50, dialect = DatabaseDialect.Oracle),
        AutoColumn(type = VARCHAR, length = 50)
    )
    var name: String? = null

    @field:Column(value = "enabled", comment = "是否启用")
    @field:AutoColumns(
        AutoColumn(type = CHAR, length = 1, defaultValue = "N", dialect = DatabaseDialect.Oracle),
        AutoColumn(type = BOOLEAN, defaultValue = "false")
    )
    var enabled: Boolean? = null
}
```

通过遵循以上规范，可以确保实体类在不同数据库之间无缝切换，同时保持代码的清晰和可维护性。
